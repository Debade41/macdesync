# macdesync

Обход блокировок по DPI на macOS без VPN — для сайтов и для голоса Discord.

На macOS нет NFQUEUE и divert-сокетов, поэтому `nfqws` из [zapret](https://github.com/bol-van/zapret) здесь не работает. macdesync делает то же самое другим путём:

- **TCP/TLS.** Локальный SOCKS5-прокси подсматривает номера seq/ack из SYN-ACK через BPF и вбрасывает перед настоящим ClientHello фейковый (через `pcap_inject`), а настоящий режет на две TLS-записи.
- **UDP.** Перед первым пакетом на новый адрес с того же сокета уходят пустышки — этого хватает для голоса Discord.
- **Все приложения сразу.** Туннель [sing-box](https://github.com/SagerNet/sing-box) заворачивает трафик системы в этот прокси.

## Запуск

Скачайте архив из [Releases](../../releases), распакуйте и следуйте `ПРОЧТИ.txt` — там же написано, что делать, если macOS не даёт открыть файл.

## Сборка из исходника

```bash
cc -O2 -Wall -o desync desync.c -lpcap
./desync -T
```

Нужны Command Line Tools. Рядом должен лежать исполняемый файл `sing-box` (в git он не хранится, в архиве релиза есть). Стратегии и ключи описаны в первых строках `desync.c`.

## Ограничения

Стратегия по умолчанию (`md5sig,tlsrec`) подобрана под одного провайдера — у другого может понадобиться другая. Нет IPv6, не помогает от блокировок по IP, не работает одновременно с VPN.
